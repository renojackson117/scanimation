▥ 스캐니메이션 제작기

여러 PNG 프레임을 세로 줄로 섞고, 검은 줄무늬 필름을 움직여 애니메이션을 만듭니다. 모든 작업은 브라우저에서 처리됩니다.

1. 소스 불러오기

선택 구간에서 지정한 프레임 수만큼 균등하게 추출합니다.

파일명 오름차순으로 정렬됩니다. 같은 크기·같은 위치의 이미지가 가장 좋습니다.

2. 출력 설정

프레임 수가 한 영역의 수용량을 넘으면 왼쪽에서 오른쪽으로 재생 영역이 이동합니다. 영상은 선택 구간에서 균등 추출합니다.
영상과 PNG 모두 적용됩니다. 변경 후 제작 / 새로고침을 누르세요.

3. PNG 저장

프레임 수는 사용자가 직접 지정하며 자동으로 변경되지 않습니다. 부족한 줄 수는 화면을 여러 구역으로 나눠 왼쪽부터 순서대로 재생합니다. 다운로드 필름은 이동 거리만큼 가로로 길어집니다. 검은 필름 PNG는 완전 검정(#000000, 불투명)과 완전 투명(알파 0) 픽셀만 사용합니다. 화면의 체크무늬는 투명 영역을 나타냅니다. 인쇄 시 합성 그림과 필름을 동일한 크기로 출력하세요.
